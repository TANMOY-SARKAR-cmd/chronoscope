# Security policy

Do not report credentials, Ed25519 private keys, enrollment credentials, operator identities, or unpublished hostnames in public issues. Use the ChronoMesh project contact channel to report vulnerabilities privately.

The community agent intentionally probes only the `sourceHost` in its local configuration. Never modify it to scan ranges, discover hosts, or run at an aggressive cadence. Revoke a compromised enrollment credential from the ChronoMesh dashboard immediately.
